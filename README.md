Propósito del sistema 
El propósito del Sistema Académico Inteligente es ofrecer una herramienta práctica y 
funcional para gestionar cursos y notas académicas de forma sencilla. 
Su diseño busca ayudar al usuario a mantener un control ordenado, actualizado y 
confiable de su rendimiento académico mediante un entorno completamente interactivo por 
consola. 
El programa está desarrollado en Python y utiliza estructuras de datos básicas (listas, 
pilas y colas) junto con algoritmos de búsqueda y ordenamiento. 
De esta manera, no solo facilita la organización de la información, sino que también 
refuerza el aprendizaje de la lógica algorítmica y la programación estructurada. 
Además, el sistema permite registrar, actualizar, eliminar, ordenar y buscar cursos, 
calcular promedios generales, clasificar aprobados y reprobados, y gestionar una cola de 
solicitudes de revisión de notas. 
Su funcionamiento es ideal tanto para fines educativos como para servir de base en 
proyectos más avanzados relacionados con la automatización de procesos académicos. 
Requisitos para ejecutar el programa 
1. Tener instalado Python 3.10 o superior. 
2. Ejecutar el archivo principal desde una terminal o desde un entorno como Visual 
Studio Code, PyCharm o Sublime Text. 
3. Contar con conocimientos básicos de manejo de consola (ingresar opciones 
numéricas, escribir datos, etc.). 
Instrucciones paso a paso para el uso del menú 
1. Al ejecutar el programa, se mostrará un menú principal con varias opciones (13 en 
total). 
2. Escriba el número correspondiente a la acción que desea realizar. 
3. Siga las instrucciones que aparecen en pantalla. 
4. Podrá realizar varias operaciones seguidas sin necesidad de cerrar el programa. 
5. Para finalizar, seleccione la opción “Salir del programa”.
